# Migration history

The files in `history/` are immutable stage reports copied from the local Minecraft 26.1.2 Fabric migration. They record the evidence, decisions, failures, and conclusions that were available at each stage.

Some intermediate conclusions were superseded by later runtime evidence or fixes. Do not treat an earlier phase report as authority for reverting a later correction.

For current implementation constraints and support status, use:

1. `AGENTS.md`;
2. `PORTING.md`;
3. `KNOWN_ISSUES.md` and `COMPATIBILITY.md`;
4. the newest applicable report in `history/`.

Read historical reports directionally by subsystem or named regression. The reports intentionally reference external evidence such as logs, screenshots, JARs, and test worlds that are not stored in this repository.
