# Exposure 1.9.18 for Minecraft 26.1.2 — Beta 1

> This is an unofficial Fabric port maintained by Filmorae. It is not an official release by Mortuusars, and port-specific issues must not be sent to the official Exposure tracker.

## Upstream and requirements

- Based on Exposure 1.9.18 by Mortuusars.
- Fixed upstream commit: `9383e0c9237099947a1e6399fcace5772f496c7d`.
- Minecraft 26.1.2.
- Java 25.
- Fabric Loader 0.19.3.
- Fabric API 0.150.0+26.1.2 or a compatible newer 26.1.2 build.
- Forge Config API Port 26.1.4.

Install Fabric Loader and the required dependencies, then place the port JAR in the instance's `mods` directory. Back up worlds and Exposure data before testing.

## Verified functionality

The controlled migration verified client startup and world entry; hand-held and Camera Stand camera flows; viewfinder controls; direct and background Capture; asynchronous photo readback, upload, storage, rendering, and export; black-and-white and color film development; Lightroom and photograph printing; Album, Signed Album, and Lectern Album flows; photograph frames; recipes and commands; save/reload behavior; integrated server; and dedicated-server startup to `Done` followed by normal stop.

The automated suite contains 58 migration tests. Common and Fabric compilation, both Access Widener validations, and the complete Gradle build passed before this draft was prepared.

## Rendering and Shader scope

No-Shader Capture was verified. A controlled compatibility matrix also covered Iris 1.11.2, Sodium 0.9.1, and BSL 8.4.01.2. Other Shader Packs, GPUs, player model layers, skin layers, and rendering mods are unverified until tested with exact version evidence.

## Compatibility warning

Compatibility with older Exposure worlds, photographs, albums, exposure repositories, or other persisted data is not guaranteed. Use a backup and a test instance. The mod id remains `exposure`, but this does not imply cross-version data compatibility.

## Known issues and support boundary

- This prerelease supports Fabric only.
- Third-party Shader and player/skin model layers may need targeted compatibility work.
- An occupied glass photograph frame replacing its front pane/highlight is fixed upstream behavior, not a port blocker.
- Optional integrations present in the source tree are not all enabled or verified.

See `KNOWN_ISSUES.md` and `COMPATIBILITY.md` for the maintained matrix.

## Migration highlights

- Ported production code through the 26.1.2 networking, persistent-data, recipe, menu, entity, item-model, GUI extraction, render-state, and frame-graph changes.
- Reworked Capture around the next complete normal world frame, an exclusive background target, and asynchronous pre-GUI readback without synchronous `glReadPixels`, extra `renderLevel`, or desktop cropping.
- Corrected 26.1.2 ARGB handling and Std140 PostChain UBO alignment.
- Preserved packet/data boundaries while restoring Album, export, recipe, frame synchronization, selfie pose, and headwear parent/child behavior.
- Added 58 regression tests and validated client, integrated-server, dedicated-server, no-Shader, and controlled Iris/Sodium/BSL paths.
